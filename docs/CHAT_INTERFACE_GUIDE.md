# 💬 Chat Interface User Guide

## Overview
PaleoLocal features an intelligent AI-powered chat interface that adapts to your exploration workflow. The chat system uses Google Gemini LLM to provide detailed geological and paleontological insights.

## 🎯 Getting Started

### Initial State
- When you first load the map, a **floating chat window** appears
- The chat is pre-loaded with context about the **top site** (highlighted marker)
- You can immediately start asking questions about paleontology or geology

### Site Exploration Workflow
1. **Browse the Map**: Explore the interactive map with paleontological site markers
2. **Click a Site**: Select any site marker to:
   - Center the map on that location
   - Open the detailed side panel
   - **Automatically dock the chat** into the panel
3. **Focused Research**: With the chat docked, ask site-specific questions

## 🎈 Chat Modes

### Floating Mode
- **Perfect for**: General questions, initial exploration
- **Features**:
  - **Draggable**: Click and drag the header to move the window
  - **Resizable**: Drag the bottom-right corner to resize
  - **Always accessible**: Floats above the map interface

### Docked Mode  
- **Perfect for**: Deep-diving into specific sites
- **Features**:
  - **Integrated**: Seamlessly fits into the site information panel
  - **Context-aware**: Automatically adapts to the selected site
  - **Space-efficient**: Uses the available panel space optimally

## 💡 Chat Tips & Tricks

### Effective Questions
```
✅ Good Examples:
"What geological formations are visible at this site?"
"When was this area formed geologically?"
"What types of fossils might be found here?"
"How does this site compare to other Mesozoic locations?"

❌ Less Effective:
"Tell me everything"
"What is this?"
```

### Context Switching
- **Site-Specific Context**: When you select a site, the chat automatically knows which location you're exploring
- **Conversation Continuity**: Your chat history is maintained when switching between modes
- **Smart Responses**: The AI provides contextually relevant information based on the selected site

## 🔧 Interaction Controls

### Moving the Chat (Floating Mode)
- Click and hold the **chat header** 
- Drag to your preferred position
- Release to set the new location

### Resizing the Chat (Floating Mode)  
- Locate the **resize handle** in the bottom-right corner
- Click and drag to adjust dimensions
- Maintain comfortable reading size

### Switching Modes
- **To Dock**: Click any site marker → chat automatically docks
- **To Float**: Close the side panel → chat returns to floating mode

## 🎓 Educational Use Cases

### Learning Scenarios
- **Comparative Analysis**: "How do the geological layers here compare to the Grand Canyon?"
- **Fossil Identification**: "What types of fossils are commonly found in Jurassic formations?"
- **Geological Processes**: "Explain the formation process that created this landscape"
- **Time Scale Questions**: "When did the geological events at this site occur?"

### Research Support
- Get contextual information about specific paleontological sites
- Understand geological time periods and formations
- Learn about fossil preservation processes
- Explore connections between different sites

## 🚀 Advanced Features

### Continuous Learning
- The chat maintains conversation history for context
- Ask follow-up questions that build on previous responses
- Reference earlier parts of your conversation

### Multi-Site Exploration
- Compare different sites by switching your selection
- Ask about relationships between different geological locations
- Build understanding across multiple paleontological sites
